# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the TRP specification, schema, or
reference tooling, please report it responsibly.

**Email:** security@striv.ai

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- The affected component (spec, schema, evaluator, or test suite).

We will acknowledge receipt within 48 hours and provide an initial assessment
within 5 business days.

## Scope

This policy covers the TRP specification, JSON Schema, reference evaluator,
conformance test suite, and CI configuration in this repository. It does not
cover third-party implementations or profiles authored by external
contributors.

## Disclosure

We follow coordinated disclosure. We ask that you do not publicly disclose a
vulnerability until we have released a fix or mitigation and have had
reasonable time to notify affected parties.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.5.x   | Yes       |

As a pre-1.0 specification, all reported issues will be addressed in the next
draft revision.
